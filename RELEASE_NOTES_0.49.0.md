# Sustainable Catalyst Workspace v0.49.0 — Research Templates & Reusable Workflows

Released: 2026-08-10

## Added

- Eight built-in research protocol templates spanning research, literature review, evidence review, decisions, systems inquiry, publication, rapid assessment, and source validation.
- Explicit application of a template to the current project.
- Explicit project-starter creation from a reusable template.
- Optional guided workflow, Notebook section scaffold, and empty starter-object creation.
- Browser-local custom template library.
- Explicit Save active workflow as template action that captures structure only.
- Integrity-fingerprinted custom-template export/import.
- Public research-templates contract endpoint.

## Data boundary

The release remains schema-stable at Storage 35 / Project 20.0 / Project Export 20.0 / Notebook Workspace 8.0. Templates do not store or copy project notes, Notebook block content, evidence, citations, findings, object references, or completion status.
