# Sustainable Catalyst Workspace v1.4.0 — Knowledge Graph & Relationship Explorer

This release makes Workspace's existing relationship model directly explorable. It adds explicit path tracing, backlink direction, relationship-source explanations, Library provenance pointer nodes, and portable graph snapshots while preserving the local-first canonical-object model.

No project/storage/export schema migration is required. v1.3.0 is the exact rollback baseline.
