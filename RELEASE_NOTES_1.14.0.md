# Sustainable Catalyst Workspace v1.14.0 — Public Research Packages & Portable Knowledge Objects

## Summary
Adds an explicit, local-first publication boundary for selected Workspace records.

## Added
- Portable Knowledge Objects.
- Public Research Package manifest/package/publication receipt contracts.
- Explicit field disclosure, licensing, publication confirmation, SHA-256 integrity, and source provenance.
- Exchange surface for private draft → explicit release → local export.

## Boundaries
No automatic publication, upload, network request, AI execution, telemetry, canonical mutation, or schema migration.
