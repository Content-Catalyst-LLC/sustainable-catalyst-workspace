# Sustainable Catalyst Workspace v1.6.0 — Workbench & Decision Studio Round-Trip Workflows

This release turns the existing generic Workbench and Decision Studio handoffs into governed round trips. Workspace can export explicitly selected project context, open the specialist surface with IDs only, provide typed return templates, validate project/handoff/destination identity on return, materialize returned calculation/simulation/scenario/decision artifacts into canonical Workspace object types, and record deterministic `derived-from` traceability to the outbound context.

Workbench and Decision Studio remain the execution environments. Workspace does not automatically upload context, execute specialist workflows, invoke AI, commit unmatched returns, mutate canonical specialist records, or migrate project/storage/export schemas. v1.5.0 is the exact rollback baseline.
