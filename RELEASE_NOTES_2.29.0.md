# Workspace v2.29.0 — Typed Client Contracts & TypeScript Migration

Workspace now generates a bounded TypeScript client contract from the authoritative backend OpenAPI surface. The browser consumes a same-origin WordPress proxy and never receives the backend service credential. Core command/query, notebook orchestration, reproducible study, and visualization-spec interactions now have strict TypeScript request contracts and a generated endpoint manifest with a deterministic OpenAPI projection SHA-256.

The v2.28.1 interaction-runtime repair remains intact. Database migrations remain through 028; v2.29.0 adds no schema migration.
