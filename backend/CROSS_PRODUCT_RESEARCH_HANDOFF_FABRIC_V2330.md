# Cross-Product Research Handoff Fabric v2.33.0

Supported products: Workspace, Knowledge Library, Research Librarian, Workbench, Research Lab, Decision Studio, Site Intelligence, Catalyst Data, Platform Core.

A handoff is a provenance envelope, not an export shortcut. Each scientific object is resolved against backend canonical state and pinned to its revision/fingerprint. The package fingerprint covers the route, intent, object pins, and context. Creation and destination acceptance produce durable receipts.

No arbitrary code execution and no generic destination mutation are introduced.
