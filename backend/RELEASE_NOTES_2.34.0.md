# Workspace v2.34.0 — Backend Policy, Identity & Authorization Consolidation

Centralizes service authentication context, WordPress user principal resolution, route-level action policy, default-deny authorization, and durable authorization decision receipts in the backend. Browser-supplied roles/scopes are never trusted. Migration 031 adds the authorization decision receipt registry.

This release preserves v2.33 cross-product handoffs, v2.32 unified scientific objects, v2.31 local-first synchronization, and the v2.28.1 interaction repair.
