# Sustainable Catalyst Workspace v3.11.0

**Release:** Documentary Evidence, Testimony & Statement Analysis Workspace

v3.11.0 adds provenance-aware documentary evidence and testimony handling to the Workspace investigative stack.

Highlights:
- Versioned document records with source fingerprints.
- Locator-preserving excerpts.
- Versioned source-backed testimony records.
- Links from documents/excerpts/testimony to claims, events, entities, external evidence, and scientific objects.
- Human-authored corroboration and contradiction relationships between testimony records.
- Documentary graph and descriptive analysis.
- Immutable documentary-analysis snapshots.
- Unified Research Context integration.
- WordPress thin-client proxy and typed-client support.
- Migration 042.
- Catalyst Analytics R 2.2.0 preserved unchanged.

Human-control boundaries remain explicit: no automatic credibility score, truth determination, evidence ranking, motive inference, culpability inference, or preferred narrative selection.
