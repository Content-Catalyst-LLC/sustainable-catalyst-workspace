# Workspace Backend v3.48.0

Linguistic Annotation & Corpus Structure Workspace.

Adds a bounded stateless annotation runtime with six operations for validation, span indexing, layer profiling, document structure, corpus structure, and annotation lineage.

Offsets use Unicode code-point indexing. Annotation and structure provenance is explicit. The v3.47.0 original-language runtime remains the upstream text/corpus foundation.

No database migration and no browser-storage schema migration.
