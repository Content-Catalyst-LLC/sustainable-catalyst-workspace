# Release Notes — Workspace v3.19.0

**Release:** Predictive Investigation & Scenario Modeling Workspace  
**Baseline:** v3.18.0  
**Migration:** 050  
**Typed endpoints:** 290 (+18)

This release adds explicit predictive scenarios, model/data fingerprint pinning, specialist forecast handoffs, calibration/backtest references, model-conditional returned results, scenario comparisons, project predictive graph/manifest/diagnostics, immutable snapshots, Unified Research Context integration, and WordPress proxy/browser adapters.

Safety boundaries remain human controlled: no automatic scenario/model selection, forecast execution, probability-as-truth, forecast-as-truth, evidence ranking, causality inference, culpability inference, or narrative selection.
