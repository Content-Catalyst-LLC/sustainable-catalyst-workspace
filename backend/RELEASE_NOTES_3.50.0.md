# Workspace Backend v3.50.0

Adds a bounded stateless Historical Language, Script & Variant Identity runtime.

The runtime validates historical language/script/variant identities, builds variant indexes, profiles temporal scope and script/orthography usage, constructs relationship graphs, and emits identity lineage.

Historical identity is preserved. The runtime does not automatically modernize languages, normalize variants, translate text, detect languages, or convert historical chronologies.

No database migration and no browser-storage schema migration.
