# Sustainable Catalyst Workspace v1.13.0 — Connected Intelligence Workspace

## Summary
Unifies explicit project context across Knowledge Library, Site Intelligence, Lab, Workbench, and Decision Studio using a common provenance-preserving connected-intelligence envelope.

- Connected Intelligence context/route/receipt schemas.
- Five-product routing vocabulary.
