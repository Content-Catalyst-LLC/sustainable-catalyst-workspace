# Sustainable Catalyst Workspace v0.7.0 — Canvas & Structured Thinking

## Release intent

v0.7.0 adds a native structured-thinking layer inside every Workspace Project. Boards connect project artifacts and working ideas without replacing the canonical Workspace Object model.

## Added

- Canvas boards with Draft / Working / Ready lifecycle.
- Draggable nodes for notes, questions, claims, evidence, data, analysis, decisions, systems, stakeholders, and ideas.
- Optional links from Canvas nodes to existing Workspace Objects.
- Typed relationships: supports, contradicts, depends on, influences, contains, causes, relates to, and sequence.
- Frames for grouping related nodes into named conceptual regions.
- Canvas synthesis that creates a canonical Document Workspace Object.
- Privacy-minimized Catalyst Canvas handoff using stable project and board IDs only.
- `sc-workspace-canvas/1.0`, project schema 6.0, storage schema 8, and handoff schema 1.5.

## Preserved boundaries

Workspace remains free, anonymous-capable, device-local, and account-aware. v0.7.0 does not add cloud project storage or collaboration. Platform conversion remains explicit and reversible.
