# Workspace v3.44.0 — Cross-Runtime ML / Neural Workflow Orchestration

Adds a governed orchestration layer across the existing classical scikit-learn and PyTorch neural runtimes. Eight bounded operations define typed workflow/step contracts, dependency validation, artifact handoffs, deterministic execution plans, run receipts, reproducibility manifests, and lineage.

Registry: 141 neural operations. No database migration. Automatic cross-runtime execution, arbitrary code, client runtime endpoints, secrets, and serialized model payloads remain disabled.
