# Sustainable Catalyst Workspace v0.45.0 — Document & Research Composition Studio

## Added
- Browser-local Composition Library with up to 80 drafts.
- Ordered authored sections for research documents.
- Explicit canonical research attachments from Integrated Knowledge.
- Explicit Citation Library attachments; missing citation data is never inferred.
- Deterministic Markdown preview with a visible Workspace traceability appendix.
- Portable composition export/import with deterministic fingerprints; imports create new draft copies.
- Explicit Create Workspace Document materialization.

## Boundaries
No automatic AI writing, citation guessing, automatic Document creation, canonical source mutation, or duplicate source-content store.

## Schema
Storage 35, Project 20.0, Project Export 20.0, Notebook Workspace 8.0, and Notebook Export 8.0 remain unchanged.
