# Sustainable Catalyst Workspace v0.46.1 — Editorial Header Rule Balance

Release date: 2026-08-10

## Purpose

v0.46.1 is a schema-stable visual patch to v0.46.0 — Workspace Import & Interchange. It retains the complete interchange feature set and corrects the Workspace editorial header rule after the 2px treatment proved visually too light.

## Editorial header correction

- Desktop top rule: **4px black**.
- Mobile top rule: **4px black**.
- Replaces the v0.46.0 2px patch.
- The original legacy 12px desktop / 9px mobile treatment remains removed.
- 4px matches recurring Sustainable Catalyst hero/header top-rule treatments; 3px remains appropriate for smaller card-level editorial rules.

## Architecture

No storage, Project, Project Export, Notebook Workspace, or Notebook Export schema changes. No canonical research content is rewritten.

## Retained v0.46.0 capability

Workspace JSON, Obsidian-ready Markdown, Notion-style CSV, Zotero/CSL JSON, portable Project exchange, staged import review, provenance, and no-silent-overwrite boundaries are unchanged.
