# Workspace v2.14.0 — Julia Simulation & Numerical Modeling Runtime

Workspace v2.14.0 promotes Julia from a registered polyglot adapter to a fully deployed, independently sandboxed runtime for bounded numerical simulation and modeling.

## Runtime operations

- linear ODE systems with RK4
- Lotka–Volterra simulation
- seeded normal Monte Carlo simulation
- convex quadratic optimization
- eigenvalue/spectral analysis
- sampled-series numerical integration
- polynomial roots through companion-matrix eigenanalysis
- bounded parameter sweeps over linear ODE systems

## Governance

The Julia service accepts only registered operations. Client-supplied Julia code, packages, runtime URLs, credentials, shell commands, and arbitrary expressions remain disabled. Results are stored in content-addressed Workspace artifacts, polyglot execution receipts, and durable numerical-simulation receipts.
