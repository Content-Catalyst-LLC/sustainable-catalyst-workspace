# Workspace v2.19.0 — Probabilistic & Bayesian Runtime

Workspace v2.19.0 adds a dedicated internal probabilistic runtime with six bounded operations: normal distribution summaries, Beta-Binomial updating, Normal-Normal updating, Gamma-Poisson updating, Beta-Binomial posterior prediction, and linear-normal uncertainty propagation.

The runtime produces reproducible posterior summaries, credible/predictive intervals, deterministic seeded simulation where sampling is required, durable result artifacts, language-neutral polyglot receipts, and dedicated probabilistic inference receipts. Arbitrary Python and package installation remain disabled.
