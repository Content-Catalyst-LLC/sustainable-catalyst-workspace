# Workspace v3.45.0 — Deep Learning Runtime Production Certification II

Workspace v3.45.0 freezes and certifies the current governed deep-learning production surface after the neural foundation, GNN, vision, sequence, multimodal, neural-symbolic, reproducible package, distributed execution, accelerator governance, model serving, and cross-runtime orchestration series.

## Certification scope

- 141 bounded neural operations; no operation expansion in this certification release.
- Registry parity between the neural service and Workspace polyglot fabric.
- Current `sc-workspace-artifact-store/1.0` persistence contract.
- Deterministic operation-registry SHA-256 fingerprint.
- v3.41.0.1 frontend continuity guardrails carried forward.
- Model serving remains non-public by default and research deployment remains non-provisioning.
- Cross-runtime workflow orchestration remains plan/receipt oriented rather than arbitrary execution.
- Client-supplied code, packages, runtime URLs, credentials, serialized modules, worker endpoints, and infrastructure mutation remain prohibited.
- Rollback baseline: v3.44.0.
- Database migration: none.

This release is intended to become the certified deep-learning production baseline before the next Workspace runtime series.
