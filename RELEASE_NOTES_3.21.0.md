# Sustainable Catalyst Workspace v3.21.0

**Release:** Neural Dataset, Tensor & Transformation Interchange

- Advances Workspace backend and WordPress package to 3.21.0.
- Preserves the separate classical scikit-learn runtime.
- Extends the PyTorch neural runtime from 4 to 8 bounded operations.
- Adds canonical neural tensor contracts and content fingerprints.
- Adds dataset manifests/reference bindings without enabling external dataset reads in the neural container.
- Adds deterministic batch planning.
- Adds bounded declarative transformation execution with transformation, input, output, and per-step lineage fingerprints.
- Carries forward the v3.20.0.1 stable-server asset coherence repair with version-matched v3.21.0 shell assets.
- Training, checkpoints, arbitrary code execution, client-supplied packages, and GPU orchestration remain disabled/out of scope.
- No database migration.
