# Sustainable Catalyst Workspace v0.40.0 — Integrated Knowledge Workspace

## Purpose
Consolidate Research Notebook, Personal Knowledge, and Research Workspace into one coherent research environment while keeping all canonical data in its existing authoritative model.

## Added
- Unified Research top-level Workspace view.
- Derived cross-surface research index for objects, notebooks, notebook blocks, research questions, and research claims.
- Search and project/kind filtering across those records.
- Canonical-origin inspector and explicit origin handoffs.
- Explicit connection inspection from recorded Notebook links and Research evidence/claim relationships.
- REST contract and JSON schemas for the Integrated Knowledge view/reference model.

## Boundaries
No duplicate integrated knowledge content store, semantic inference, automatic AI, automatic mutation, or background network activity. v0.39 Notebook Review & Provenance and v0.38 conflict-safe sync remain intact.

## Schema
This is a schema-stable consolidation release: storage 35, Project 20.0, Project Export 20.0, Notebook Workspace/Export 8.0.
