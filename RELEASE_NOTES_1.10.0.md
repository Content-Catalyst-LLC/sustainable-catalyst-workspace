# Sustainable Catalyst Workspace v1.10.0

## Workspace Automation & Research Operations

Productionizes the existing local Research Automation foundation into deterministic, user-controlled Research Operations. Adds eight operation types, due-state planning, explicit run queues, blocked-target visibility, reviewable runs, metadata-only SHA-256 receipts, and backward-compatible legacy routine import.

No background execution, automatic network request, automatic task creation, automatic AI, telemetry, or canonical mutation is introduced. Storage 35, Project 20.0, and Export 20.0 remain frozen.
