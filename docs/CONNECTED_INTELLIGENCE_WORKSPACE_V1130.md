# Workspace v1.13.0 — Connected Intelligence Workspace

Workspace becomes the contextual layer across Knowledge Library, Site Intelligence, Lab, Workbench, and Decision Studio without absorbing their specialist execution domains.

## Common context
A single versioned context envelope carries explicit project and record identifiers, object types, provenance, citations, and traceability needed for a specialist handoff. URLs carry stable IDs only; project content is never embedded in a route URL.

## Connected products
- Knowledge Library — research continuity and Library-origin provenance.
- Site Intelligence — geographic, event, country, observation, and evidence context.
- Lab — scientific models, graphs, experiments, Bayesian work, transformations, and scientific reports.
- Workbench — calculations, simulation, optimization, engineering and transformation workflows.
- Decision Studio — scenarios, decision packets, recommendations, risks, and outcome plans.

## Boundaries
Connected Intelligence is explicit and local-first. It does not create background federation, automatic cross-product execution, automatic network requests, automatic context uploads, automatic return commits, automatic AI, behavioral/query telemetry, or mutation of canonical specialist records. Storage 35 / Project 20.0 / Export 20.0 remain frozen.
