# v0.75.0 — Institutional Package & Handoff Validation

## Purpose
Validate institutional disclosure and promotion artifacts before transfer while preserving Workspace as an independent personal source environment.

## Validation gates
- Exact frozen research-package scope and disclosure counts.
- Required receiving institution/organization and transfer purpose.
- Source-project revision comparison with visible stale-package attention.
- Promotion-package manifest consistency and SHA-256 payload verification.
- Privacy and governance boundary checks.
- Explainable handoff readiness review without numeric scoring.
- Receipt schema, local handoff/project match, duplicate detection, chronology review, and SHA-256 verification when provided.
- Explicit acknowledgement before exporting a stale snapshot or committing an unsigned/chronologically unusual receipt.

## Boundaries
Validation does not grant organization access, create an institutional tenant, auto-upload a package, auto-ingest into Catalyst Intelligence, mutate the personal source project, or certify institutional acceptance.

## Canonical schema
Storage 35, Project 20.0, Project Export 20.0. No migration.
