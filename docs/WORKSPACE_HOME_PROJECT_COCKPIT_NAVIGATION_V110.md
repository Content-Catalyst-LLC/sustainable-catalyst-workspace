# Workspace Home, Project Cockpit & Navigation Refinement — v1.1.0

The Workspace Home is an orientation surface, not a second object store. Metrics and next actions are derived from canonical browser-local Workspace state each time Home renders. No dashboard data is persisted separately.

The Project Cockpit surfaces the active project, recent context, canonical object counts, research/notebook counts, and direct routes into Projects, Research, Notebook, Analysis, Decision and Briefing modes. Suggestions are deterministic and inspectable. They do not score productivity or infer user intent.

The primary navigation remains five areas: Home, Projects, Research, Review and Exchange. Review retains every historical governance, accessibility, deployment, certification, recovery and GA surface, but less-common routes are progressively disclosed under More review tools.

Storage 35, Project 20.0 and Export 20.0 remain frozen. No migration, background sync, automatic AI, automatic project mutation or behavioral telemetry is introduced.
