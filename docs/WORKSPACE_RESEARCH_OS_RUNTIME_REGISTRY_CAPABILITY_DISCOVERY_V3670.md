# Workspace v3.67.0 — Research OS Runtime Registry & Capability Discovery

v3.67.0 adds a descriptive registry above the certified v3.60–v3.66 Research OS runtime chain.

Registered runtimes: v3.60 Agentic Research Workflow; v3.61 Human Governance, Approval & Intervention; v3.62 Multi-Agent Orchestration & Specialist Coordination; v3.63 Reproducible Agentic Research Package; v3.64 Integrated Research OS; v3.65 Production Certification & Agentic Runtime Consolidation; v3.66 Unified Research Session & Lifecycle Persistence.

Capabilities: normalized runtime descriptors; schema/version discovery; runtime enumeration/lookup; capability discovery; operation discovery; authority-boundary matrix; compatibility discovery; portable read-only registry snapshots.

Authority boundary: the registry describes runtimes; it does not invoke them. It cannot activate capabilities, dispatch operations, mutate runtime state, approve governance, publish, rank evidence, determine truth, perform external side effects, or make decisions. Upstream runtime authority remains authoritative.

Migration: no database migration; no project-schema migration; rollback target v3.66.0.
