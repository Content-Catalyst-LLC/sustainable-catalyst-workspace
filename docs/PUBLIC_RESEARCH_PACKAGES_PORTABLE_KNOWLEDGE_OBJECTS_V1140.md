# Workspace v1.14.0 — Public Research Packages & Portable Knowledge Objects

Adds an explicit publication boundary between private canonical Workspace records and portable public projections. Users explicitly select records and disclosed fields, choose a license, build a private draft package, explicitly confirm release, and export locally. Canonical Workspace records remain unchanged.

## Boundaries
Private by default. No automatic publication, upload, network request, AI action, telemetry, canonical mutation, or schema migration. Storage 35 / Project 20.0 / Export 20.0 remain frozen.
