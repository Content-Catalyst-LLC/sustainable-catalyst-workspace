# v0.28.0 — Project Audit Trail & Governance Ledger

Workspace now exposes one inspectable chronological view of consequential actions while preserving each underlying ledger as the source of truth. The Audit environment derives events at render/export time and stores no duplicate audit database.

## Sources
Project activity; Version History; account recovery; cross-device sync; Safe Actions; reconciliation and Decision Receipts; Collaboration; Institutional Handoff; Share; Import & Interoperability.

## Governance
- Derived events are read-only.
- No hidden governance score or people ranking.
- No automatic compliance inference.
- Portable audit JSON excludes project/object content.
- Storage schema remains 26 and project schema remains 11.0.
