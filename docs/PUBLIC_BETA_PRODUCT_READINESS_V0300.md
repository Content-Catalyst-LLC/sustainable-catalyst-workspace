# Public Beta & Product Readiness — v0.30.0

## Purpose

v0.30.0 changes the entry experience, not the governance model. Workspace already contains mature research, evidence, analysis, decision, briefing, knowledge, recovery, collaboration, reconciliation, lifecycle, and institutional-handoff capabilities. Public beta consolidates those systems behind a clearer first-use path.

## Product entry model

`Start` is the default top-level view. It offers a blank project, a recent project, the Knowledge Library, and four guided pathways. Advanced environments remain available in the navigation and render when selected.

## Quick starts

1. Research Investigation
2. Analytical Assessment
3. Decision Case
4. Publication Preparation

Quick starts instantiate existing guided workflows. They do not create hidden content or automatically complete methodological steps.

## Local capability status

Workspace checks local browser support for storage, session storage, SHA-256/Web Crypto, file import/export, same-origin return handoffs, online state, and reduced-motion preference. The result is `ready` or `limited`; no numerical score is calculated.

## Governance boundary

Public beta does not create a login wall, automatic cloud upload, background sync, automatic lifecycle advancement, behavioral telemetry, or a hidden readiness score. Guest Workspace remains functional. Institutional governance remains downstream in Catalyst Intelligence after explicit promotion/acceptance.

## Schema boundary

- Storage schema: 27 → 27
- Project schema: `sc-workspace-project/12.0` unchanged
- No migration required

## Accessibility target

WCAG 2.2 AA remains the target. v0.30.0 strengthens keyboard navigation, focus visibility, reduced-motion behavior, forced-colors support, and active-view semantics.
