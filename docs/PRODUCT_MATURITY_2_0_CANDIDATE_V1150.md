# Workspace v1.15.0 — 1.x Product Maturity & 2.0 Candidate

v1.15.0 closes the planned 1.x maturity line. It adds an evidence-based maturity dossier across twelve dimensions, an explicit compatibility matrix, a 1.x deprecation register, and a human-controlled 2.0 candidate boundary.

A candidate designation is not a 2.0 release. It introduces no v2 project/export/storage schema, performs no migration, and does not automatically promote or mutate Workspace. Any eventual 2.0 release requires a separate release contract, migration design if needed, release evidence, and explicit deployment.

The maturity model has no numeric or hidden score. Each dimension is Ready, Attention, or Blocked, and any unresolved Blocked dimension prevents candidate designation.
