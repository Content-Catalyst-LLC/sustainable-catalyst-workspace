# v0.9.0.1 — Closing CTA Cleanup & Action Alignment

The public closing band now offers two actions with distinct purposes:

1. **New Project** — opens the existing local project-creation workflow and moves the viewport to the form.
2. **Explore the Library** — opens the canonical Sustainable Catalyst Knowledge Library at `/knowledge-libraries/`.

The removed **Open Workspace** action was redundant because the closing band already appears after the embedded Workspace application.

No persistence, project, object, identity, traceability, handoff, or route contract changes in this release.
