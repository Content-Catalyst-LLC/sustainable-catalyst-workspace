# Workspace v1.9.0 — Institutional Governance, Provenance & Audit Studio

This release unifies existing Workspace governance records into a derived Institutional Audit Studio. Audit dossiers reference authoritative ledgers rather than replacing them. Evidence scope is explicit, provenance and decision lineage remain visible, attestations are user supplied, and portable audit packages carry integrity metadata without claiming regulatory certification.

## Evidence families
Audit Trail; Version History; Reconciliation Receipts; Shared Review Room snapshots; Decisions; Institutional Handoff; Knowledge Graph; Project Lifecycle; Citation Library; Provenance.

## Boundaries
No compliance score, automatic compliance inference, external submission, automatic canonical mutation, automatic AI, behavioral telemetry, query telemetry, or schema migration.
