# Workspace v0.60.0 — Public Product Beta II

Public Product Beta II treats Workspace as one complete public product. The release adds an explicit local beta gate across persistence, integrity support, recovery, focused route isolation, performance diagnostics, security/privacy controls, portability, and release identity.

## Boundaries

- Checks are local and advisory.
- No behavioral telemetry or automatic submission.
- No hidden readiness/productivity score.
- No automatic repair or canonical research mutation.
- v0.59.1 focused route isolation remains required.
- Storage 35 / Project 20.0 remain unchanged.
- The 4px editorial header rule remains unchanged.
