# Workspace v0.8.3 — Advisory Visual Integration & Workspace Editorial Shell

v0.8.3 is a visual/editorial integration release. It does not change storage schema 9, project schema `sc-workspace-project/7.0`, the canonical object model, identity boundary, handoff/return contracts, or the stable `/platform/` route.

## Design basis

The public shell is intentionally aligned with the Sustainable Catalyst Advisory page's institutional design grammar: strong editorial hierarchy, two-column hero composition with a software surface, alternating white and warm-neutral sections, selective black emphasis bands, sharp rules, restrained red accents, numbered workflow modules, and a deliberate closing action surface.

Workspace remains visually distinct as an interactive personal working environment. The goal is family resemblance, not duplication.

## Public editorial shell

- Two-column hero with concise product proposition and an illustrative project preview.
- Three-column access summary for free access, optional account identity, and device-local persistence.
- Editorial workflow section connecting Research → Evidence → Analysis → Decision → Canvas.
- Black/red continuity band showing the reasoning chain that remains visible across stages.
- Workspace Pathways section using structured rows rather than marketing cards.
- Personal Capability section distinguishing local-first personal work from institutional Catalyst Intelligence.
- Dedicated application introduction and stronger full-width software frame.
- Black closing call-to-action aligned with the broader Sustainable Catalyst page rhythm.

## Application behavior

All v0.8.2 functionality remains intact. Storage/identity and connected-workflow diagnostics stay progressively disclosed. Project mode navigation remains Overview, Research, Analysis, Decisions, Canvas, and Objects.

## Navigation and route

The public navigation label remains Workspace. `/platform/` remains the stable canonical route. The guarded navigation relabel and rollback tools introduced in v0.8.2 remain unchanged.
