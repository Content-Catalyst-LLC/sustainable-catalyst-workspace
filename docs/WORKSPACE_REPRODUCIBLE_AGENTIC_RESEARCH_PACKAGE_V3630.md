# Workspace v3.63.0 — Reproducible Agentic Research Package

This release packages the v3.60 agent workflow, v3.61 human-governance history, and v3.62 multi-agent coordination record into a portable, content-addressed, integrity-verifiable research package.

The package is descriptive, not authoritative. It cannot execute or replay work, approve actions, bypass governance, mutate source objects, promote claims, rank evidence, determine truth, or create external side effects.

Bounded operations: validate, create, add-object, add-receipt, add-governance, finalize, verify, snapshot.

Captured materials may include workflow state, specialist teams and assignments, receipts, syntheses and dissent, evidence and claims, datasets and models, notebooks and visualizations, artifacts and publications, runtime/environment metadata, final outputs, provenance references, governance records, and SHA-256 integrity digests.
