# Research Tasks & Workflow State — v0.52.0

Workspace v0.52.0 adds explicit browser-local workflow tasks around canonical Integrated Knowledge records.

## Task types

- Review needed
- Verify claim
- Source required
- Citation incomplete
- Ready for synthesis
- Follow-up
- Custom

## Workflow states

Open, in progress, blocked, done, and dismissed. Every state change is recorded in task-local history.

## Boundary

Tasks contain canonical pointers, not copied research content. Task state is separate from research state. Completing or deleting a task never edits its referenced record. Missing targets remain visibly unresolved. No automatic task creation, completion, AI action, or canonical mutation is introduced.
