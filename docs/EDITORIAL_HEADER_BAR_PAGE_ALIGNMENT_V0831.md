# v0.8.3.1 — Editorial Header Bar & Page Alignment

This release adds the black editorial header bar used as a visual anchor across Sustainable Catalyst product/editorial pages. It sits directly above the Workspace hero and spans the public Workspace content canvas. The change is intentionally presentation-only.

## Contract
- Header bar class: `scw-editorial-header-bar`
- Desktop height: 12px
- Mobile height: 9px
- Solid black, sharp edges, no text
- No storage or project migration
- Canonical route remains `/platform/`
- Public navigation label remains `Workspace`
