# Sustainable Catalyst Workspace v2.0.0 — Connected Knowledge Workspace

- Promotes Workspace to the stable 2.0 product line.
- Adds one v2 Connected Knowledge context contract across Workspace, Knowledge Library, Site Intelligence, Lab, Workbench, Decision Studio, review/audit, public knowledge, and developer extensions.
- Preserves v1 REST contracts and v1 project/export compatibility.
- Retains Storage 35 / Project 20.0 / Export 20.0; no automatic migration is required.
- Adds explicit v1 compatibility registry and metadata-only Connected Knowledge receipts.
- Preserves local-first ownership, explicit sync/collaboration, provenance, auditability, public-projection controls, and specialist-tool boundaries.
- Exact predecessor and rollback baseline: v1.15.0.
