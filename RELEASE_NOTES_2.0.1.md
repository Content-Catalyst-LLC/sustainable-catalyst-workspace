# Sustainable Catalyst Workspace v2.0.1
## Button System, Control Alignment & Interaction-State Repair

A surgical post-2.0 UI repair that normalizes action controls throughout Workspace. The release addresses inconsistent secondary buttons, awkward Connected Knowledge/Connected Intelligence wrapping, misleading black status/output panes, weak drawer-state labels, disabled-control ambiguity, and control alignment while preserving the v2.0.0 architecture and frozen data schemas.

No project migration, canonical content mutation, JavaScript interaction redesign, background behavior, automatic AI, or telemetry is introduced.
