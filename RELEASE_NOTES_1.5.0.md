# Sustainable Catalyst Workspace v1.5.0 — Lab & Scientific Workspace Integration

This release deepens the Workspace ↔ Lab boundary without moving scientific computation into Workspace. It adds explicit scientific context packages, Lab workflow routing, typed scientific return artifacts, preserved methodology/units/uncertainty metadata, and deterministic `derived-from` traceability from selected Workspace context to returned Lab outputs.

Lab execution remains explicit. Workspace does not automatically upload project content, run Lab workflows, infer scientific relationships, or commit unmatched returns. No project/storage/export schema migration is required. v1.4.0 is the exact rollback baseline.
