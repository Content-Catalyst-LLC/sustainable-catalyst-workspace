# Sustainable Catalyst Workspace v1.2.0

**Universal Workspace Search & Knowledge Retrieval**

- Adds a universal in-browser search index over projects, objects, notebooks, research records, analysis questions, decisions, briefing drafts, Citation Library references, and Research Tasks.
- Reuses the existing deterministic Advanced Retrieval ranker and exposes ranking reasons.
- Keeps saved searches browser-local and preserves canonical-origin navigation.
- Adds `/wp-json/sc-workspace/v1/universal-search-contract`.
- Keeps Storage 35 / Project 20.0 / Export 20.0 frozen.
- Adds no server index, embeddings, query telemetry, automatic AI, hidden personalization, or canonical mutation.
