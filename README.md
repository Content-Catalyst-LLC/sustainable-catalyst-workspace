# Sustainable Catalyst Workspace v2.2.0 — Persistence Migration, Object Storage & Recovery Hardening

v2.2.0 extends the dedicated Workspace backend introduced in v2.1.0 with a non-destructive WordPress `user_meta` migration path, SHA-256 content-addressed artifact storage, storage-integrity checks, and bounded recovery snapshots. Browser-local projects remain canonical and existing Workspace project/export schemas remain unchanged.

See `RELEASE_NOTES_2.2.0.md`, `docs/PERSISTENCE_MIGRATION_OBJECT_STORAGE_RECOVERY_V220.md`, `docs/DEPLOY_WORKSPACE_BACKEND_V220.md`, `VALIDATION_REPORT_2.2.0.md`, and `backend/README.md`.
