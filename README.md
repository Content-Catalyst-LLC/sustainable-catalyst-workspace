# Sustainable Catalyst Workspace v0.83.0

## Live Production Certification & Release Sign-Off

Sustainable Catalyst Workspace is a free, local-first environment for carrying questions, evidence, analysis, decisions, composition, review, and deliberate handoff across Sustainable Catalyst.

v0.83.0 remains inside the pre-1.0 feature freeze. The release adds a human-controlled production sign-off surface that records the live field checks left open by the Release Candidate line. It never auto-certifies production: every check must be explicitly attested, and incomplete exports remain marked `pending`.

Canonical contracts remain frozen at Storage 35, Project `sc-workspace-project/20.0`, and Project Export `sc-workspace-project-export/20.0`.
