# Sustainable Catalyst Workspace v0.80.0

## Workspace Release Candidate I

Sustainable Catalyst Workspace is a free, local-first environment for keeping questions, evidence, analysis, decisions, composition, review, and deliberate handoff connected. v0.80.0 establishes the formal Release Candidate boundary after the Public Beta III automated defect backlog was closed in v0.79.0.

The product is now **feature-frozen** for the pre-1.0 certification sequence. Remaining work is limited to defects, deployment, compatibility, accessibility, performance, recovery, security/privacy, documentation, packaging/rollback, and findings from explicit field validation. The new **Review → Release Candidate** surface keeps the automated RC gate separate from production WordPress, assistive-technology, physical touch/zoom/contrast, multi-hour large-project, two-device continuity, and real external-handoff validation.

Storage remains **35**. Project and Project Export remain **20.0**. No migration is required.

See `RELEASE_NOTES_0.80.0.md`, `VALIDATION_REPORT_0.80.0.md`, and `docs/WORKSPACE_RELEASE_CANDIDATE_I_V0800.md` for release details.
