# Sustainable Catalyst Workspace

Current release: **v0.45.0 — Document & Research Composition Studio**

Workspace is a local-first research and decision environment for Sustainable Catalyst.

v0.45.0 adds browser-local structured composition drafts that assemble user-authored sections with explicit canonical research pointers and Citation Library references. Drafts can be previewed, exported/imported, and deliberately materialized into canonical Workspace Document objects. The release remains schema-stable at storage 35 / Project 20.0 and does not copy canonical research into a parallel composition store.
