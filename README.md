# Sustainable Catalyst Workspace

Current release: **v0.48.0 — Cross-Project Knowledge**

Workspace is the free, local-first Sustainable Catalyst research environment.

v0.48.0 adds explicit cross-project knowledge references: a project can reference canonical research owned by another project without copying the source record or changing ownership. Each reference records the source pointer, target project, relationship, and optional context note in a browser-local ledger. References integrate into the Research Graph as explicit edges, remain visibly unresolved if a source or target is unavailable, and can be exported/imported without embedding canonical research content. Storage remains 35 / Project 20.0, and the v0.46.1 4px editorial header rule remains retained.
