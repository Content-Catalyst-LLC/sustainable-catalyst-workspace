# Sustainable Catalyst Workspace v0.71.0

**First-Run Onboarding & Project Creation**

Sustainable Catalyst Workspace is a free, local-first environment for keeping questions, evidence, analysis, decisions, composition, review, and deliberate handoff connected. v0.71.0 focuses on the first five minutes of use: a new user can name the work, optionally describe its purpose, and explicitly create either a blank project or one of four guided project structures without encountering a login wall.

The first-run surface appears only when Workspace has zero local projects. Project creation occurs only after an explicit submit action. Guided starts reuse the existing canonical project and workflow machinery; they do not infer intent, pre-complete research, upload content, enroll sync, advance lifecycle state, or invoke AI automatically.

Canonical formats remain schema-stable at **Storage 35**, **Project `sc-workspace-project/20.0`**, and **Project Export `sc-workspace-project-export/20.0`**.

See `RELEASE_NOTES_0.71.0.md`, `VALIDATION_REPORT_0.71.0.md`, and `docs/FIRST_RUN_ONBOARDING_PROJECT_CREATION_V0710.md` for release details.
