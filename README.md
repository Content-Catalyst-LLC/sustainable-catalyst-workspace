# Sustainable Catalyst Workspace

Current release: **v0.46.1 — Workspace Import & Interchange**

Workspace is a local-first research and decision environment for Sustainable Catalyst.

v0.46.1 unifies Workspace interchange around explicit compatibility profiles for structured Workspace JSON, Obsidian-ready Markdown, Notion-style CSV, Zotero-compatible CSL JSON, and portable Project packages. Imports remain staged for human review, external metadata is never silently invented, and portable Project imports continue to open as new local copies. The release is schema-stable at storage 35 / Project 20.0. It also aligns the Workspace editorial top rule with the broader Sustainable Catalyst site at a restrained 2px on desktop and mobile.
