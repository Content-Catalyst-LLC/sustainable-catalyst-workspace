# Sustainable Catalyst Workspace v3.9.1

Workspace v3.9.1 is a narrow production promotion of Catalyst Analytics R from provider v2.1.0 to v2.2.0. It preserves the v3.9.0 Timeline, Event Reconstruction & Investigative Sequence Workspace, adds no database migration, and keeps the production R runtime bounded, non-root, and read-only.
