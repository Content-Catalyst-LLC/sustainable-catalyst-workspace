# Workspace v1.11.0 — Developer API, SDK & Extension Contracts

Adds a stable versioned Developer API contract, browser-local SDK, extension manifests, explicit capability grants, portable extension envelopes, and a Developer API surface within Exchange → API & Embed. Extensions remain read-only/descriptive by default; no mutation REST endpoints, arbitrary code execution, remote extension loading, secret-bearing manifests, automatic AI, telemetry, or canonical schema migration are introduced.
