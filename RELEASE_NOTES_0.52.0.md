# Sustainable Catalyst Workspace v0.52.0 — Research Tasks & Workflow State

## Summary

Adds explicit browser-local research tasks attached to canonical Integrated Knowledge references. Tasks carry type, state, priority, optional due date, owner label, notes, and task-local transition history.

## Governance

- Task state is separate from research state.
- Tasks store canonical pointers, not copied research content.
- Completing, blocking, dismissing, importing, exporting, or deleting tasks does not mutate referenced research.
- Unresolved targets remain visible.
- No automatic task creation, completion, AI action, or canonical mutation.
- Storage 35 / Project 20.0 remain unchanged.
- The 4px editorial header rule remains unchanged.
