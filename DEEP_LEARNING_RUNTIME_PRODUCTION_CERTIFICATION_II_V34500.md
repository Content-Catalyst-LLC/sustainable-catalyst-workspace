# Deep Learning Runtime Production Certification II — v3.45.0

## Purpose

Workspace v3.45.0 is a production certification release, not a model-family expansion. It freezes the 141-operation governed neural surface established through v3.44.0 and certifies the integrated runtime as one production baseline.

## Certified domains

1. GNN foundation, training, evaluation, explainability, and graph embeddings.
2. Computer vision and remote-sensing neural inference.
3. Temporal sequence models and neural forecasting.
4. Multimodal vision + sequence fusion.
5. Neural-symbolic bounded research intelligence.
6. Reproducible deep-learning research packages.
7. Distributed worker planning, leases, failover, and receipts.
8. Accelerator scheduling and resource governance.
9. Package-backed model serving and deterministic batch inference.
10. Cross-runtime classical ML ↔ neural workflow orchestration.

## Certification invariants

- Exactly 141 registered neural operations.
- Operation registry is fingerprinted deterministically with SHA-256.
- All execution remains bounded to registered declarative operations.
- Artifact persistence uses `sc-workspace-artifact-store/1.0`.
- Neural outputs remain model-derived analytical artifacts unless separately grounded as evidence.
- Public network exposure is disabled by the research deployment layer.
- Infrastructure mutation is disabled.
- Client-supplied code, package installation, runtime URLs, credentials, worker endpoints, and opaque serialized models are rejected.
- Frontend CSS/JS continuity thresholds remain enforced.
- WordPress plugin identity remains canonical.
- Rollback baseline is v3.44.0.
- No database migration.

## Production posture

The v3.45 certification does not claim that every possible neural workload is validated. It certifies the explicitly registered and tested Sustainable Catalyst Workspace runtime surface and its guardrails.
