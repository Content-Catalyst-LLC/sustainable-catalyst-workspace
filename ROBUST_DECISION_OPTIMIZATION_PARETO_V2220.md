# Workspace v2.22.0 — Robust Decision Optimization & Pareto Analysis

Adds a bounded decision-analysis runtime above v2.21 optimization and v2.20 uncertainty quantification. The runtime supports Pareto-front construction, normalized expected-utility ranking, minimax regret, robust constraint analysis, empirical stochastic dominance, robustness envelopes, stress-scenario ranking, and value-of-perfect-information analysis. Every durable decision job stores a provenance-aware decision optimization receipt. Arbitrary code execution remains disabled.
